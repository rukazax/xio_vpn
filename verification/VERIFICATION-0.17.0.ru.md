# XIO 0.17.0 — протоколы и исходный стиль

Дата: 18 октября 2026. Испытательная Android-сборка 0.17.0+18. Идентификатор пакета и сертификат подписи сохранены; APK можно устанавливать поверх прежнего XIO.

## Результат

Возвращена палитра до оформления ECONA: фон #0c1119, поверхности #151e2a, акцент #c0f57b, текст #e7efde; светлая тема #f2f5ef. Noto Sans и локальные арабский, деванагари, CJK-шрифты сохранены. Системное переключение темы, компактная навигация, свайпы и 16 вариантов ярлыка сохранены. Четыре файла шрифтов побайтно совпадают с выпуском0.14. После чистой установки проверены русские [тёмный](android-clean-dark-017.png) и [светлый](android-clean-light-017.png) экраны; тестовые профили удалены из эмулятора.

К четырём прежним Android-движкам добавлены шесть действующих адаптеров: Xray, Shadowsocks, OpenVPN, OpenVPN/Cloak, системный IKEv2/IPsec и встроенный Tailscale с Headscale/DERP. Серверная установка разворачивает все десять подключений; профиль нового пользователя содержит настройки каждого. Автоопределение импорта, выбор движка, приоритет и последовательное переключение работают с расширенным набором. Старые профили не получают новые секреты автоматически — после обновления установки сервера нужен новый пользователь.

## Проверка Android → реальный VPS

Android API 35 x86_64, эмулятор5556; Debian12 amd64, 81.177.142.37. Сайт проверки в лаборатории явно задан как https://1.1.1.1/cdn-cgi/trace. Время ниже — от нажатия до отображения результата, включая накладные расходы UI-автоматизации; это не бенчмарк задержки.

| Движок | Результат | Время наблюдения |
|---|---|---|
| WireGuard | HTTP 200 | 5.38 с |
| AmneziaWG 3.1 | HTTP 200 | 5.19 с |
| RIVET / H3 | HTTP 200 | 5.34 с |
| RIVET / S1 | HTTP 200 | 5.42 с |
| Xray / REALITY | HTTP 200 | 5.27 с |
| Shadowsocks | HTTP 200 | 5.25 с |
| OpenVPN | HTTP 200 | 5.21 с |
| OpenVPN / Cloak | HTTP 200 | 5.45 с |
| IKEv2 / IPsec | HTTP 200 | 6.05 с |
| Tailscale / Headscale | HTTP 200 | 9.16 с |

Первый повторный запуск RIVET/S1 превысил бюджет и переключился на H3; следующая попытка S1 успешна. Поэтому таблица подтверждает работоспособность, но не непрерывную безотказность. Подробности: [android-protocols-017.json](android-protocols-017.json).

Отдельное Android-приложение с другим UID подтвердило внешний IP VPS через Xray, OpenVPN/Cloak, IKEv2; аналогичная отдельная проверка Tailscale также вернула этот IP. Go-клиенты Xray и Shadowsocks дополнительно прошли HTTPS с проверкой exit IP и настоящие UDP DNS-запросы. Embedded Tailscale прошёл тест TUN → exit node → DNS. Это реальные сетевые проверки, а не имитация статуса подключения.

При временном запрете TCP4443 на VPS выбранный Xray стал недоступен; приложение автоматически перешло на RIVET/H3 и получило HTTP200 за 12.87 с. Тестовое правило удалено. См. [android-fallback-017.json](android-fallback-017.json).

После удаления задачи XIO из списка последних приложений туннель продолжал передавать трафик отдельного приложения. Плитка быстрых настроек отключила и заново подключила VPN, не открывая Activity XIO. См. [android-background-tile-017.json](android-background-tile-017.json). Принудительная остановка приложения средствами Android и ограничения энергосбережения Honor — отдельные случаи и на физическом телефоне не проверены.

По умолчанию сохранён youtube.com. Системный DNS VPS не разрешил www.youtube.com; прямой запрос к Quad9 вернул адреса, но HTTPS-запрос с этими адресами завершился TLS timeout. Доступность самого YouTube с данного VPS этим выпуском не подтверждена. Успехи HTTP200 в таблице относятся к указанному лабораторному сайту. В настройках можно выбрать другой сайт; недоступный контрольный сайт приведёт к перебору протоколов даже при работающем туннеле.

## Установка и очистка сервера

На реальном Debian12 выполнена установка всех протоколов. В двух отдельных QEMU VM проверены установка, создание пользователя, статистика, отзыв и очистка: Ubuntu24.04 с UFW и CentOS Stream9 с firewalld и SELinux Enforcing. Добавлены ограниченные правила SELinux и AppArmor, без их отключения. По окончании очищены принадлежащие XIO файлы, правила и пакеты; SSH сохранился. Доказательства: [Ubuntu](vm-lifecycle-017-ubuntu.json), [CentOS](vm-lifecycle-017-centos.json).

На VPS отозваны временные пользователи этого выпуска, тестовые правила удалены. Установленные службы XIO оставлены для дальнейших испытаний. Существующие SSH, nginx, Apache и почтовые службы сохранены. Очистка не стирает общие системные журналы и не удаляет чужие пакеты.

Счётчики объединяют WG/AWG, RIVET, Xray/SS, OpenVPN/Cloak, IKEv2 и Tailscale. Добавлены проверки повторного чтения, переподключения, смены месяца и rekey IKE, чтобы не удваивать месячный трафик. Отзыв удаляет серверные права и ключи, закрывает доступные активные сеансы. После отзыва активного профиля Xray отдельное Android-приложение перестало получать Интернет через него; результат: [android-revoked-user-017.json](android-revoked-user-017.json). Изменение пользователей Xray/Cloak сейчас перезапускает их службы: это может прервать текущие сеансы других пользователей этих движков.

## Проверки сборки и зависимостей

* Flutter analyze: без замечаний. Flutter test: 83 успешных, 4 пропущенных платформенных теста. Каталоги: 13 языков ×363 сообщения, проверены реальные шрифты и RTL.
* Go1.27.2: race-тесты и vet пройдены. gRPC обновлён до1.83.2, устранив найденные GO-2026-6443 и GO-2026-6348. govulncheck: 0 уязвимостей в вызываемом коде; 4 предупреждения уровня зависимостей для неиспользуемых путей. Это не независимый аудит.
* Серверный Python: 10 тестов пройдены. OpenVPN3 JNI пересобран для трёх ABI из включённых исходников с проверкой хешей.
* Все APK: подписи и zipalign проверены, в скомпилированном манифесте16 launcher-alias и одна включённая иконка. Android разрешает launcher.green_dark_0 как точку запуска. Загружаемые секции Go/OpenVPN совпадают со свежими нативными сборками; различия от Gradle stripping не скрывают устаревшую библиотеку.
* 64-битные ELF имеют выравнивание PT_LOAD не менее16KiB; legacy ARM32 проверен на4KiB. APK выровнены zipalign с параметром16KiB.

## Поддерживаемые конфигурации и ограничения

Xray: VLESS REALITY/TLS, VMess AEAD, Trojan TLS и один зашифрованный outbound в безопасном JSON. Shadowsocks: SIP002/JSON, в собственной установке SS2022. OpenVPN: встроенные ключи/CA/сертификаты, без внешних скриптов и файлов; Cloak дополняет OpenVPN. IKEv2: EAP username/password с доверенным CA; PKCS12-импорт не реализован. Tailscale: controlURL, CA, auth key и exit node; импорт произвольной учётной записи через OAuth не реализован. Конфигурации с allowInsecure отклоняются.

IKEv2 требует Android11+ и системной поддержки IPsec. На неподдерживаемом устройстве он исключается из автоматического выбора. Локальные байтовые счётчики IKEv2 недоступны, поэтому не показывается выдуманный ноль; месячная статистика берётся с сервера. Раздельное туннелирование для системного IKEv2 в этой реализации не поддерживается; соответствующий режим завершается ошибкой и разрешает перейти к следующему движку.

Новые нативные адаптеры этого выпуска доступны в Android. Полный перенос в клиенты Windows/Ubuntu не выполнен; существующий desktop-адаптер Tailscale CLI сохранён. Варианты ОС кроме Debian12/Ubuntu24/CentOS9 включены в ограниченную матрицу установщика, но не получили отдельного испытания. Установщик рассчитан на amd64 и systemd.

Не проверены физический Honor Magic V3, сети операторов разных стран, долговременная нагрузка, полный DNS/IPv6 leak и kill-switch аудит каждого нового движка, независимый криптоаудит и неразличимость трафика для DPI. RIVET остаётся экспериментальной композицией; абсолютная устойчивость к блокировкам не заявляется. Автоматический перебор подтверждён при установлении соединения; непрерывный контроль доступности и переход между всеми новыми движками при обрыве уже работающего сеанса не подтверждён.
