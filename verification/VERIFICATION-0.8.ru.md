# x1o 0.8.0 — автоматическое доверие SSH

17 октября 2026 года. Из мастера VPS удалены поле «Доверенный SSH-отпечаток» и инструкция получения отпечатка. Указываются адрес, порт, пользователь и пароль либо SSH-ключ. VPN-движок, установка WireGuard и службы тестового VPS не менялись.

Первый публичный ключ автоматически запоминается в `ssh-known-hosts.json` каталога данных приложения **до аутентификации**. Это TOFU: независимой проверки личности сервера при первом соединении нет. Дальнейшее изменение ключа того же адреса/порта останавливает соединение. Пароль и закрытый ключ в это хранилище не записываются. Имя DNS нормализуется по регистру; пользователь не меняет идентичность узла, другой порт учитывается отдельно. Привязка по разным DNS-именам/IP не объединяется.

Записи сериализованы внутри процесса, сохраняются через временный файл и переименование. Повреждённое хранилище или ошибка сохранения приводят к отказу соединения; существующий ключ автоматически не перезаписывается. Для внутренних инструментов сохранена возможность явно задать ожидаемый отпечаток, но интерфейс его больше не требует.

## Проверки

- Flutter analyze: без замечаний — `flutter-analyze-0.8.log`.
- 49 тестов прошли, 2 внешних сетевых/VPS-теста пропущены. Набор включает живой локальный SSH-сервер: `flutter-tests-0.8.log`.
- Два SSH-теста отдельно с подробным выводом: `ssh-transport-0.8.log`. Первое подключение без отпечатка, повторное подключение через новый экземпляр сервиса, отклонение изменившегося ключа. Счётчик серверной парольной аутентификации не увеличивается при несовпадении ключа. Явное закрепление ключа также проверено.
- Отдельные проверки: неизменность ключа после отказа, разный порт, одинаковый узел для разных пользователей/регистра DNS, конкурентные первые подключения, повреждённый JSON, отказ записи с последующим успешным повтором.
- Виджет мастера открывается без поля отпечатка и команды ssh-keygen; адрес и пароль доступны. Существующие тесты свайпов, тем, размеров экранов и раздельного туннелирования прошли.

Локальная SSH-лаборатория слушает только loopback; не исполняет команды ОС и не требует root, TUN или маршрутов хоста. Проверка VPS и установки на Debian в этом выпуске не повторялась. Последние сетевые результаты приведены в отчёте0.6. Физический Honor Magic V3 и Windows/Ubuntu-бинарные сборки этой версии не проверены.

## Подписанный Android APK

Три ABI собраны; подпись, совпадение сертификата с0.7 и16KB zipalign проверены: `android-apks-0.8.json`. x86_64 release установлен поверх0.7 на Android API35: мастер VPS открыт, четыре поля (адрес, порт, пользователь, пароль), поля отпечатка нет, пустой адрес корректно отклоняется. `android-ssh-setup-0.8.json`. Учётные данные в эмулятор не вводились. FLAG_SECURE мастера сохранён; снимок чувствительного экрана намеренно не создавался.

ARM64 APK отправлен через @x1oorgbot в ранее подтверждённый личный чат, сообщение16. Ответ API проверен по chat id и размеру документа; безопасная квитанция — `telegram-apk-delivery-0.8.json`. Это подтверждает доставку, а не установку на телефон.
