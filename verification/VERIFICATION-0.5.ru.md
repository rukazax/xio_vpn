# Проверка xio 0.5.0 — раздельное туннелирование

Дата: 17 октября 2026. Android: WireGuard и AmneziaWG; Ubuntu/Windows эта функция не затрагивает.

## Реализация

Общие для всех профилей правила задаются на главном экране или в «Ещё». Сохранение только при выключенном VPN. Один сериализованный native worker применяет правила в Engine.connect, включая запуск из плитки Android. Конфигурации и ключи в vault не переписываются. Списки приложений и IP хранятся в отдельном атомарном no-backup файле. Не входят в экспорт профилей/диагностики.

Режимы: маршруты профиля для всех приложений; выбранные приложения через VPN; выбранные приложения в обход; выбранные IP через VPN; выбранные IP в обход. Режимы приложений и IP не комбинируются. IP/CIDR: IPv4/IPv6, до128 записей, ограничение4096 результирующих маршрутов. IP-выбор пересекается с AllowedIPs профиля либо вычитается из них. Домены и автоматическая маршрутизация DNS не реализованы. Зональные адреса и IPv4-mapped IPv6 не поддерживаются.

Ожидание завершения предыдущего VPN-сервиса защищает быстрое переподключение от повторного использования службы с уже запланированным stopSelf. Публикация Android per-UID сети после создания TUN асинхронна; интеграционные проверки дают ОС одну секунду перед открытием нового TCP-сокета. Ранее открытые сокеты приложениям следует переподключить.

## Подтверждено

- Flutter analyze: без замечаний.
- 36 локальных тестов прошли;2 внешних fixture-теста пропущены. Включены поиск/выбор/сохранение, ошибки при активном туннеле, пустой список включения, восстановление IP-правил; ширины320/784, обе темы, шрифт130%. Существующие проверки темы/навигации/безопасности сохранены.
- Production Java-калькулятор IP: IPv4/IPv6, граничные хосты, нормализация, отказ от hostname/неверных масок, пересечение с исходными маршрутами,20480 проверок взаимодополняемости включения/исключения. Запуск: `python3 tools/check-ip-routes.py`.
- Android API35, изолированная Go/netstack лаборатория без изменения маршрутов хоста:18 сценариев реального HTTP через WG/AWG. Для каждого движка проверены5 вариантов приложений и4 варианта IP. Запросы выполнялись от UID xio; выбор другого пакета использовался для проверки обхода xio. Список других приложений получен через PackageManager. Это не тест реального трафика каждого выбранного стороннего приложения.
- При активном туннеле изменение правил отклоняется. Неизвестный режим, пустое включение и недоступный пакет отклоняются. Повреждение файла правил и IP-правило вне AllowedIPs профиля блокируют активацию. Возврат к корректным правилам восстанавливает работу.
- Точные результаты: `android-split-routing-0.5.json`; журналы `android-split-integration-0.5.log`, `ip-routes-tests-0.5.log`, `flutter-tests-0.5.log`.

## Проверка подписанного APK

Три ABI: подписи APK и16KB zipalign проверены; сертификат совпадает с0.4. Точные хеши: `android-apks-0.5.json`. Подписанный x86_64 APK установлен на Android API35. В реальном Android UI проверены выбор/сохранение приложения и IP-правил с IPv4/IPv6, восстановление обоих вариантов после принудительного завершения процесса, светлый/тёмный редактор, ширины360 и784 при шрифте130%. Главная кнопка и нижняя навигация доступны на360×800. Подробности и PNG: `android-split-release-ui-0.5.json`.

ARM64 APK отправлен ранее подтверждённому пользователем личному чату Telegram через @xioorgbot, message12; подтверждение API и хеш файла: `telegram-apk-delivery-0.5.json`. Это подтверждение доставки файлу в чат, а не установки на телефон.

## Границы проверки

Honor Magic V3 физически не подключался. IPv6-пакеты, DNS через пользовательский VPS, системный lockdown, shared-UID приложения и цензурирующие сети здесь не проверены. Для IPv6 подтверждена алгебра маршрутов, а не выход IPv6 в интернет. Прямой выход исключённого трафика — выбранное поведение, а не обещание защиты всего устройства.

Показываются приложения с launcher activity; невидимые сервисы отдельно не выбираются. Системный запрет соединений без VPN может запретить обход. При изменении/удалении выбранного пакета пользователь должен обновить правила. Для включения DNS в VPN добавьте его IP в IP-правила и убедитесь, что профиль разрешает этот маршрут. Иначе DNS может перестать работать.

Debian VPS: TCP22 отвечает и предъявляет ED25519 ключ. Отпечаток запрошен для независимой сверки. Пароль не использован, аутентификация/установка/туннель на VPS не проверены. Текущий автоматический установщик по-прежнему ограничен Ubuntu24.04; его совместимость с Debian не заявляется.

Основания API: [Amnezia split tunneling](https://docs.amnezia.org/ru/documentation/instructions/vpn-split-tunneling/), [Android VpnService.Builder](https://developer.android.com/reference/android/net/VpnService.Builder).
