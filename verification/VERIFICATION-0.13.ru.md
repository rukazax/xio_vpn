# XIO 0.13.0+13 — серверы, администраторы и нативная плитка

## Реализовано

- Три нижние кнопки: главная, настройки, добавление; увеличенные иконки, подписи скрыты, доступные названия для скринридера сохранены. Переключение свайпами сохранено. Пользователи доступны из настроек и через «+ → Добавить пользователя».
- Общая ширина диалогов согласована с окном импорта; на экране 360dp поле SSH-мастера занимает 298dp. Содержимое прокручивается при нехватке высоты.
- SSH-пароль/ключ сохраняются отдельно от метаданных. Android: AES-GCM, Keystore, закрытый no-backup каталог. Windows: код DPAPI (исполнение на Windows не проверено). Ubuntu: AES-GCM с локальным файлом ключа 0600 в каталоге 0700; это не защита от скомпрометированной учётной записи ОС. При отсутствии/недоступности старого секрета потребуется первоначальный ввод.
- Повторные операции автоматически подключаются с сохранёнными полномочиями. Сервер можно переименовать, экспортировать текстом или файлом `xio-server://`. Экспорт намеренно содержит секрет подключения: передавать только доверенному получателю. В обычном профиле пользователя root-пароля нет.
- Флаг страны рядом с сервером/адресом: GeoIP, приблизительное местоположение, 🌐 при отсутствии сведений. Рецепт запрашивает страну своего VPS, клиент — страну endpoint для самостоятельных конфигураций. Источник: [документация ipapi](https://ipapi.co/api/).
- Администратор получает ограниченный Ed25519 SSH-ключ с forced command/restrict. Проверка роли и лимита выполняется сервером. Лимит означает число действующих дочерних пользователей; отзыв освобождает место. Создавать других администраторов, отзывать чужих пользователей, открывать shell/port forwarding и удалять сервер делегированному администратору запрещено. Отзыв администратора отзывает его дочерних пользователей.
- Роль admin/user, on/off по недавнему handshake, месячный трафик UTC. Устаревший статус отображается как неизвестный. Обновление страницы каждые30с; это оценка активности, не точный индикатор сессии. Счётчики переживают перезапуск; возможна потеря несохранённого интервала и погрешность около границы месяца до периода выборки.
- Плитка Android использует отдельную нативную foreground-службу, не открывая Flutter Activity. План содержит ID профилей и HTTPS-сайт, секретов в плане нет. Первое разрешение VPN выдаётся в приложении. Сам VPN живёт в foreground-службе независимо от экрана приложения.

Для успешной сетевой проверки адрес в эмуляторе изменён на `https://example.com` через настройки. Значение по умолчанию в выпуске — `https://youtube.com`. YouTube из тестовой сети/VPS не ответил в пределах таймаута: клиент перебрал оба протокола и отключился. HTTP200 от example.com не означает доступность/воспроизведение YouTube.

Тестовый Android — собственный эмулятор API35 x86_64, 360×800dp, масштаб текста1.3. Связь итогового APK с результатами: `android-ui-0.13.json`, `android-native-lifecycle-0.13.json`, `android-delegated-recipient-0.13.json`, `vps-android-dataplane-0.13.json`. Переименование/перенос owner-конфигурации и первичное создание администратора проверялись на предварительной сборке0.13; делегированный импорт, работа выданного ключа, квота и оба туннеля — на проверочном кандидате с тем же нативным VPN-кодом. После финальных правок ширины/флага/самоотзыва повторены WireGuard HTTP200 и жизненный цикл плитки. Оба хеша сохранены в android-ui-0.13.json.

После SIGKILL процесс запускался вручную до подтверждения автоматического восстановления; восстановление после уничтожения процесса не подтверждено. START_STICKY не является гарантией непрерывности. Force-stop и ограничения питания производителя могут остановить VPN. Физический Honor Magic V3, Windows и политики энергосбережения MagicOS не проверены.

## VPS

На Debian12 amd64 удалена прежняя управляемая установка XIO с тремя пользователями, конфигурациями, службами и собственными сетевыми правилами. Других известных VPN-служб/пакетов/контейнеров при инвентаризации не обнаружено. UDP443 принадлежит nginx/QUIC: web, mail, FastPanel, SSH и чужие правила сохранены. Общесистемные журналы не стирались.

Затем установлен свежий WireGuard/AmneziaWG для испытаний. Конечное состояние зафиксировано отдельно в `vps-final-state-0.13.json`; временные тестовые пользователи и делегированные ключи отозваны. Свежие службы оставлены для дальнейших разрешённых испытаний. Это не удаление произвольного ПО по сигнатуре и не обещание отсутствия следов у ОС/провайдера.

## Границы выпуска

Полный набор AmneziaVPN, Android Tailscale/Headscale и экспериментальные RIVET пока не интегрированы. Рабочие Android-движки — WireGuard и AmneziaWG3.1. Не выполнены независимый аудит, тесты DPI разных стран, полная проверка утечек, физическое устройство и Windows-бинарная сборка.

Артефакты: `releases/XIO-0.13.0-*`, `releases/SHA256SUMS`. Исходники исключают .signing/.build-support и приватные профили. Проверка архивов сканирует известные локальные секреты; она не является универсальным аудитом утечек.

APK ARM64 доставлен через существующего бота x1oorgbot; подтверждение Telegram, ID сообщения и SHA256 — в `telegram-apk-delivery-0.13.json`. Делегирование требует серверной части XIO0.13.
