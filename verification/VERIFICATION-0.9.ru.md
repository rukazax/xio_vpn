# x1o 0.9.0 — промежуточный выпуск

Изменены структура экранов, многопротокольные пользовательские профили, автоматический выбор рабочего протокола, настройка сайта проверки/приоритета, установка/удаление управляемого VPS и серверные счётчики.

**Полный запрос пользователя ещё не выполнен:** установлены и подключаются только WireGuard и AmneziaWG. Остальные протоколы AmneziaVPN и исполняемые транспорты RIVET не реализованы. Удаление произвольных сторонних VPN также не реализовано. Подробная матрица — [AMNEZIA-UI-AND-SCOPE-0.9.ru.md](AMNEZIA-UI-AND-SCOPE-0.9.ru.md).

## Реальный Debian VPS

На81.177.142.37 создана отдельная управляемая установка. Она не изменяла конфигурации Nginx/Apache/MySQL/FASTPANEL, почты или SSH.

Два независимых пользователя передали зашифрованный HTTP-трафик по обоим протоколам через изолированные userspace-клиенты. Отзыв первого пользователя остановил оба его протокола, второй сохранил доступ. Счётчики обоих пользователей были ненулевыми; накопленные значения сохранились после перезапуска AWG. Затем программный uninstall удалил установку и восстановил forwarding. Артефакты: `vps-managed-tunnels-0.9.json`, `vps-managed-lifecycle-0.9.json`.

Это реальные SSH/UDP-соединения с VPS, не локальный mock; userspace-клиенты не создавали TUN и маршруты рабочего компьютера. Вторая установка выполнена уже **через Android-приложение**. SHA256 загруженного admin.py совпал с исходником: `android-vps-install-0.9.json`. При неверном serverId административная команда была отклонена до изменений.

## Android API35

Проверяется установленный подписанный release APK x86_64. Это эмулятор, не физический Honor Magic V3.

- SSH-мастер установил оба протокола и создал профиль владельца. Дополнительный пользователь создан через раздел общего доступа приложения.
- Стартовый сайт настроек — `https://youtube.com`; для положительного сетевого испытания явно выбран `https://example.org`.
- AmneziaWG получил HTTP200. После остановки AWG приложение автоматически перешло на WireGuard и также получило HTTP200. Этот тест проверяет доступность указанного сайта, не видео YouTube.
- Между разными UID Android передан файл профиля через FileProvider. Лабораторный получатель прочитал обе конфигурации, проверил отсутствие полей SSH/административного доступа, не сохранял ключи. Его исходник — `lab-share-receiver/Receiver.java`; снимок — `android-share-receiver-0.9.png`. Внешним контактам профиль не отправлялся.
- Файл `.x1o` импортирован через системный Android DocumentsUI, в том числе после обнаружения того же пользователя через статистику. Импортированный профиль подключился по AWG и получил HTTP200.
- Команда плитки проверена при холодном старте и при уже запущенном Activity. Физическое нажатие плитки в панели быстрых настроек этим тестом не подменяется.
- Серверные счётчики обновлены через SSH из интерфейса приложения; снимок — `android-user-statistics-0.9.png`.

После ручного отключения старый результат проверки сайта очищается. Перед открытием административного диалога снимается фокус с формы, чтобы клавиатура не открывалась снова после закрытия диалога. Экран SSH остаётся защищённым FLAG_SECURE; снимки с вводом пароля/ключей не создавались.

## Ограничения

Физический Honor, новая сборка Windows/Ubuntu, воспроизведение YouTube, DNS/IPv6 leak-аудит, DPI разных стран и криптографический аудит не проверялись. При раздельном туннелировании HTTPS-запрос следует правилам маршрутизации приложения. Серверный рецепт здесь — Debian12 amd64, IPv4-выход; IPv6 клиента захватывается и блокируется. Счётчики могут потерять несохранённый интервал перед аварией.

Удаляется только собственная управляемая установка и принадлежащие ей файлы/ключи/правила/пакеты. Общие системные журналы не стираются; обещания отсутствия всех следов нет. Исторические отчёты0.6 и ранние установки этого VPS описывают уже удалённое состояние.

## Итоговая сборка и состояние VPS

Три ABI подписаны прежним сертификатом, прошли apksigner и16KB zipalign; файлы/размеры/SHA256 — `android-apks-0.9.json`. ARM64 APK28.6МБ рассчитан на Honor. Итоговый x86_64 APK отдельно подтвердил исправление клавиатуры, HTTP200 по AWG, автоматический переход на WireGuard при остановленном AWG, очищение результата проверки при отключении и удаление сервера вместе с локальными профилями. Результаты ранних подписанных кандидатов0.9 отделены от финального APK в `android-managed-e2e-0.9.json`.

После удаления через приложение на VPS нет управляемых VPN-интерфейсов, портов51820/51821, ключей, конфигураций, служб, правила NAT и пакета wireguard-tools. Forwarding снова0. Nginx, Apache, MySQL, SSH, FASTPANEL, Dovecot, Exim и FTP активны: `vps-managed-final-removal-0.9.json`. Остался пустой служебный runtime-lock `/run/lock/x1o-managed.lock`; общесистемные журналы также сохраняются. Это не криминалистическая очистка всех следов.

ARM64 APK доставлен в ранее подтверждённый личный Telegram-чат через @x1oorgbot, сообщение18: `telegram-apk-delivery-0.9.json`. Доставка не подтверждает установку на физический Honor.
