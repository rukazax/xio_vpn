# x1o 0.7 — навигация свайпами и удаление вводных блоков

17 октября2026. Изменения относятся к интерфейсу Flutter. VPN-службы, сервер, ключи, установщики и криптографические движки не менялись.

## Изменения

- Горизонтальный PageView: Главная → Серверы → Протоколы → Тесты → Ещё; свайпы в обе стороны, без зацикливания. Нижняя навигация и боковое меню синхронизированы с текущей страницей. Программный переход «Добавить подключение» открывает «Серверы» тем же механизмом.
- Каждая посещённая вкладка сохраняет свою вертикальную прокрутку и состояние формы. Адрес/порт тестирования сохраняются при перелистывании и переходе между ширинами390/900. Во время смены вкладки фокус поля снимается; скрытые вкладки исключены из фокуса, поэтому возврат из вложенного экрана не открывает клавиатуру для невидимого поля. Сохранение формы относится к навигации внутри процесса, не к перезапуску приложения.
- Удалены все три блока из пользовательских скриншотов: «Сделано для контроля / x1o / X in,1out / Много входов…», «X IN / Один интерфейс. Разные пути. / Доступность зависит…», «Много путей. Один выход. / Выбирайте свой путь в сеть. / Протокол, сервер…».
- Удалены другие повторные вводные тексты, плашка EARLY ACCESS, длинная инструкция про шторку, поясняющая карточка под подключением, повторные примечания в карточках протоколов. Приватность и журнал раскрываются по нажатию. Ошибки, подтверждения действий, статусы доступности протоколов и лицензии сохранены. Объём передачи подписан короче, чтобы метрики оставались в одну строку на узком экране.
- Сохранённые домашняя и настроечная карточки раздельного туннелирования обновляются после изменения правил, без устаревшей подписи на другой вкладке. Нативное применение правил не менялось.

## Автоматическая проверка

Flutter analyze — без замечаний. Прошли42 теста,3 внешних fixture/VPS-теста пропущены по умолчанию. Новый набор проверяет оба направления свайпов и границы на360×800/784×720, синхронизацию с нажатиями, переход из основной кнопки, сохранение адреса/порта, обновление AppStore, складывание/раскрытие390↔900, независимую вертикальную прокрутку. Отдельная регрессия подтверждает обновление обеих сохранённых карточек маршрутизации после изменения правил.

Существующие проверки темы, компактной навигации, конфигураций/хранилища и раздельного туннелирования также прошли. Журналы: `flutter-analyze-0.7.log`, `flutter-tests-0.7.log`, `swipe-tests-0.7.log`. Снимки виджетов записываются с суффиксом0.7; исторические изображения0.6 не переписываются.
