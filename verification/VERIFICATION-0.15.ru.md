# XIO 0.15.0+15 — проверка интерфейса и переключения

Дата:18.10.2026, Europe/Moscow. APK подписаны прежним сертификатом XIO; ARM64 предназначен для Honor Magic V3. Физический телефон в этой среде недоступен.

Изменения: тайм-аут попытки5–60с, по умолчанию15с; общий срок проверки HTTPS/handshake, отмена запроса, остановка неудачного туннеля и переход к следующему протоколу пользователя. Настройка сохраняется в JSON и нативном плане плитки. Ожидание разрешения VPN и работа службы ОС не входят в сетевой тайм-аут. Desktop-адаптер Tailscale также использует общий бюджет для команд и сайта, но сетевое испытание Tailscale в этом выпуске не проводилось.

Повторный сетевой прогон обнаружил гонку со старым периодическим чтением состояния. `StatusPoll` объединяет обычные запросы и позволяет началу попытки дождаться отдельного свежего чтения после предыдущего туннеля. Сценарий покрыт регрессионным тестом; поздний ответ проверки предыдущего протокола не может заменить результат следующего.

Страница пользователей: три строки — имя/цветной admin при наличии/online или offline; месячный трафик в десятичных GB; действия доступа. Имя сохранено в первой строке для различения записей. Подробности протоколов, время обновления и ручная кнопка удалены. Настройки показывают число записей списка. Однократный SSH-снимок запускается после загрузки приложения и не повторяется при открытии страницы или возврате из фона. Если сервер недоступен, хранится последний успешный снимок; online/offline не является непрерывным мониторингом.

Палитра и системный стек шрифтов сверены с актуальным HTML/CSS econa.su (получен HTTP200): Ink/Slate/Mist/Lagoon, светлая тема, диалоги, карточки и ярлыки. Светлый текстовый акцент затемнён для читаемости. Noto Sans входит в системный стек сайта; локальные fallback сохранены. Пункт поддержки открывает https://x1o.org/pay через системный браузер. DNS имени в этой среде не разрешился, доступность страницы не подтверждена.

Сетевой стенд — одноразовая Ubuntu24.04 VM с QEMU user networking; SSH и UDP доступны только через локальные порты. Изолированный Android-эмулятор API35,360×800, fontScale1.3. Профиль содержит AmneziaWG с намеренно закрытым UDP-портом и рабочий WireGuard. Тайм-аут для испытания5с, сайт https://example.com. На итоговом APK переход с AWG на WG наблюдался через5.07с, HTTPS200 подтверждён. Время измеряется по смене активного профиля после предварительно выданного разрешения VPN. Доказательства и точный хеш APK: android-fallback-0.15.json. Плитка без Activity переключилась через5.04с, Activity не открывалось, проверка завершилась и повторный клик отключил VPN. Публичный VPS81.177.142.37 в этом выпуске не изменялся.

Однократный запрос статистики проверяется счётчиком `status` в административном скрипте **только одноразовой VM**; содержимое запросов и ключи не журналируются. Доказательства: android-startup-statistics-0.15.json. Скриншоты карточек с демоданными: user-cards-ru/en/ar-dark/light-0.15.png; Android: android-user-cards-0.15.png, android-home-fallback-0.15.png. Демоданные не выдаются за реальные пользовательские счётчики.

Проверки не являются аудитом криптографии, тестом DPI в разных странах, доказательством отсутствия всех утечек или воспроизведения YouTube. Android поддерживает WireGuard и AmneziaWG3.1; остальные ранее запрошенные движки ещё не интегрированы. Сетевые проверки установки/удаления на Debian12, Ubuntu24.04/UFW и CentOS Stream9/firewalld/SELinux относятся к выпуску0.14, а не к повторному прогону0.15.

Рабочие временные ключи и SSH-доступ одноразовой VM не входят в архивы; проверка известных секретов выполняется до удаления тестовых файлов. Сетевые измерения привязаны к хешу итогового x86_64 APK, а подпись/выравнивание проверяются для всех трёх ABI.
