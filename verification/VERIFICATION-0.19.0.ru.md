# XIO 0.19.0 — подтверждения и ограничения

Дата: 18 октября 2026. Это кандидат для испытаний новых платформ, а не сертификация безопасности и не завершённый iOS-релиз.

## Подтверждено

* Flutter analyze: без замечаний. Flutter tests: 92 успешных, 4 пропущенных платформенных проверки; дополнительно прошёл новый тест шифрованного импорта/экспорта полного профиля10протоколов. Пропуски не объявляются успешными испытаниями устройства.
* Go race tests прошли для desktop, mobile, tailclient, xrayclient и rivet. Отдельно прошли реальные VPS packet-flow тесты apple для H3 и S1; это Go-пакет в Ubuntu, не NetworkExtension в iOS.
* Ubuntu release ELF собран и показал экран первого запуска с реальными шрифтами в Xvfb на Ubuntu. Набор распространяется как DEB и переносимый архив. Главное приложение не меняет маршруты до запроса подключения.
* В отдельной Ubuntu24.04 VM проверен каждый из 7 движков: WireGuard, AmneziaWG, RIVET/H3, RIVET/S1, Xray, Shadowsocks, Tailscale. Для каждого curl HTTPS к api.ipify.org получил HTTP200 и внешний IP VPS 81.177.142.37; запрос к example.com также завершился HTTP200 для каждого движка. Результаты — ubuntu-vm-protocols-019.json.
* После обычного отключения правила и DNS вернулись к исходным. После SIGKILL помощника последующее подключение восстановило принадлежащие XIO правила и снова передало HTTPS; окончательное отключение удалило их.
* HMAC идентичности локального помощника, отказ без bearer, отказ браузерному Origin, ограничение тела запроса и запрет произвольного метода проверены без изменения сети рабочего ПК. WG/AWG парсер отвергает shell hooks и параметры вне допустимых числовых пределов.
* Windows: compiled PE32+ exe, настоящий Windows-target AOT snapshot, Go Windows helper и официальный Wintun DLL. Под Wine отдельный QA entry point подтвердил Platform.isWindows, DPAPI CurrentUser round trip, шифрованный CRUD и 7 capabilities помощника. QA entry point не входит в production main.
* iOS: проект Xcode разобран после добавления target PacketTunnel, зависимости, embed phase, источников и entitlements. Swift frontend проверил синтаксис; gobind с GOOS=ios создал настоящие Objective-C объявления для экспортируемого Go API. Это не Xcode typecheck/link/sign.

## Ограничения

* Экран первого запуска Windows-клиента отрисован под Wine с реальным текстом и шрифтами; для QA в отдельном Wine-префиксе установлен официальный Microsoft d3dcompiler_47. Холодный запуск наблюдали до45сек; это не измерение скорости на Windows. Нативного Windows-хоста для UAC, установки Wintun, firewall/DNS и 7 сквозных соединений пока нет; результаты Linux не выдаются за Windows.
* Для iPhone/iPad нет подключённого Mac/Xcode, Team ID и provisioning. IPA отсутствует. Код PacketTunnel ещё не компилировался и не испытывался на iPhone; memory budget, переход Wi-Fi/cellular, сон и app lifecycle остаются непроверенными.
* OpenVPN/Cloak/IKEv2 пока не портированы в настольный runtime; iOS слой подготовлен только для двух RIVET-транспортов.
* Youtube.com недоступен с тестового VPS даже в прямом curl: ошибка DNS подтверждена отдельной базовой проверкой vps-web-baseline-019.json. Его недоступность не объявляется ошибкой всех рабочих туннелей и не обходится отключением TLS-проверки. В приложении проверочный сайт настраивается пользователем.
* IPv6 пользовательского трафика блокируется при активном туннеле, полноценного IPv6 транспорта нет. Изоляция между попытками, DNS leak matrix всех ОС, независимый аудит, DPI/география и физические iOS/Windows-устройства этим выпуском не подтверждены.
* Существующий Android APK0.18 не перестраивался. Изменённые исходники Go0.19 не являются доказательством актуальности старого Android native fingerprint. Старый релиз и его доказательства сохранены отдельно.
* Артефакты не подписаны сертификатом Windows-издателя, App Store/TestFlight не публиковались. Выход в публичные магазины и юридическая совместимость всего дополнительного состава требуют отдельной окончательной проверки.

Первоначальные неудачные проверки и промежуточные журналы сохранены для воспроизводимости. Основная актуальная матрица — ubuntu-vm-protocols-019.json; ранний rivet-debug-log относится к исправленному адаптеру virtio/GSO.

После испытаний принадлежащие XIO VPN-компоненты удалены с VPS. Проверены отсутствие каталогов установки и сохранение состояний SSH, web и mail служб: vps-cleanup-019.json. Это не удаление общих журналов ОС. Локальная Ubuntu VM выключена; результаты и отдельный overlay сохранены.
