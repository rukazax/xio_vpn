# Contributing / Участие в разработке

Discuss a substantial change in an issue first. Send a focused pull request describing the problem, resulting behaviour and tests. Keep secrets and generated build caches out of commits. Run `flutter analyze` and `flutter test` from `app/`; run appropriate Go tests for tunnel changes. Respect each dependency's licence. Contributions to original XIO code are accepted under GPL-3.0-only; no copyright transfer is requested.

Крупное изменение сначала обсудите в issue. В pull request опишите проблему, результат и проверки. Не включайте секреты и кеши сборки. Из `app/` выполните `flutter analyze` и `flutter test`; при изменении туннелей выполните соответствующие Go-тесты. Соблюдайте лицензии зависимостей. Вклад в собственный код XIO принимается под GPL-3.0-only без передачи авторских прав.
