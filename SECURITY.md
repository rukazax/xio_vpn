# Security / Безопасность

Report vulnerabilities privately to **er-ka@mail.ru**. Include the XIO version, platform, reproduction steps and expected impact. Remove passwords, access tokens and private keys. Do not attach a live profile. No response-time commitment or independent security certification is claimed.

Об уязвимостях сообщайте лично на **er-ka@mail.ru**. Укажите версию XIO, платформу, шаги воспроизведения и предполагаемые последствия. Удалите пароли, токены и приватные ключи. Не прикладывайте действующий профиль. Срок ответа и независимая сертификация безопасности не заявляются.

RIVET is experimental. Test builds are not a substitute for an independent audit. / RIVET экспериментальный. Испытания сборок не заменяют независимый аудит.
