# XIO 0.16 — RIVET на Android и VPS

[APK ARM64 для Honor Magic V3](releases/XIO-0.16.0-android-arm64-v8a.apk) · [исходники](releases/XIO-0.16.0-source.zip) · [отчёт испытаний](verification/VERIFICATION-0.16.ru.md) · [профиль протокола](RIVET-IMPLEMENTATION-0.2.ru.md) · [предыдущий выпуск](history/README.0.15.0.ru.md)

XIO означает **X in 1 out**. В Android работают WireGuard, AmneziaWG3.1 и два новых экспериментальных транспорта RIVET. RIVET-S1 переносит внутренний TLS1.3 через WSS; RIVET-H3 — внутренний QUIC/TLS1.3 через HTTP/3 CONNECT-UDP. Это собственная композиция стандартных криптографических примитивов, а не новый шифр. Полный набор остальных движков AmneziaVPN и Android Tailscale/Headscale пока не интегрирован.

## Изменения 0.16

- Все четыре Android-движка объединены в один Go runtime; отдельная libx1o-awg больше не загружается. Это устраняет конфликт cgo при смене движка. Мобильный runtime использует прежнюю приватную CLOCK_BOOTTIME-правку таймеров; криптобиблиотека не изменяется.
- Новый Go-клиент и сервер: независимый внутренний SPKI pin, только гибридная группа X25519MLKEM768, HMAC-аутентификация устройства с привязкой к TLS exporter, отдельный входной токен, канонический CBOR, ограничения кадров, памяти, соединений и частоты запросов. Вход и шлюз работают от разных системных пользователей. Аутентификация сервера ECDSA остаётся классической; независимый криптографический аудит не проводился.
- Установщик из приложения добавляет все четыре работающих протокола. Профиль нового пользователя содержит четыре подключения; импорт определяет движок автоматически, экспорт не включает root-доступ. Ранее выданные двухпротокольные профили автоматически новые секреты не получают: создайте нового пользователя после обновления установки сервера.
- При обрыве RIVET сохраняет TUN, отбрасывает пакеты без защищённого сеанса и пытается восстановиться через другой RIVET-транспорт. Внешний автоматический выбор четырёх движков использует пользовательский тайм-аут и HTTPS-проверку. Время handshake учитывается в бюджете попытки.
- RIVET добавлен в общую Android VpnService, плитку быстрых настроек, уведомление и раздельное туннелирование. Работа не зависит от открытого Activity. Для системного запрета соединений без VPN включите Always-on VPN и «Блокировать соединения без VPN» в настройках Android. На отдельном эмуляторе проверены холодный запуск плиткой и восстановление после перезагрузки.
- IPv4, MTU1280, публичные назначения. IPv6 в полном туннеле захватывается и отбрасывается; частные сети, адреса шлюза и IP-фрагменты не поддерживаются. Раздельное туннелирование намеренно допускает обход VPN по заданным пользователем правилам.
- Серверная статистика объединяет месячный трафик четырёх протоколов. Отзыв удаляет секреты RIVET и закрывает сеанс в пределах5с. Установщик учитывает UFW/firewalld, собственные пакеты/файлы/правила, откатывает незавершённую установку RIVET и не стирает общие системные журналы.

Проверка сайта по умолчанию — https://youtube.com; адрес меняется в настройках. После проверки ответов DNS на VPS в RIVET и новых управляемых профилях используется9.9.9.9; DNS сторонних импортированных конфигураций сохраняется. Обычный DNS за VPS не защищён от вмешательства. HTTPS к одному из адресов YouTube недоступен даже с самого VPS. На этом сервере задайте проверку https://1.1.1.1/cdn-cgi/trace; дефолт youtube.com сохранён по заданию. Воспроизведение видео не подтверждено.

## Сервер и импорт

Поддерживаемая матрица установщика: Debian12/13, Ubuntu22.04/24.04/26.04, CentOS Stream/Rocky/Alma/RHEL9/10, x86_64, systemd, TUN, IPv4. В этом выпуске проверены Debian12, Ubuntu24.04 с UFW и CentOS Stream9 с firewalld/SELinux Enforcing. Другие версии из матрицы не проверены физически.

Порты: UDP51820 WireGuard, UDP51821 AmneziaWG, TCP/UDP8443 RIVET; внутренние порты7443/7444 доступны только через loopback. Порт8443 выбран для совместимости с уже работающим веб-сервером VPS и легко блокируется по номеру. Внешний публичный сертификат предпочтителен; без него создаётся отдельный CA конкретного профиля. Автоматического продления сертификатов пока нет: см. ограничения в профиле реализации.

Root-пароль/SSH-ключ хранится отдельно в защищённом хранилище и автоматически используется при управлении. Обычный пользовательский экспорт не содержит SSH-доступа. Экспорт сервера содержит передаваемые административные реквизиты. Изменённый SSH-ключ сервера не принимается молча. Очистка удаляет только собственную управляемую установку XIO; произвольные сторонние VPN и общие журналы ОС не удаляются.

Сохранены 13 языков, системная тема, палитра сайта-образца, компактная навигация, иконки, серверы/пользователи, делегированные администраторы и лимит действующих пользователей из0.15. Статистика обновляется один раз при запуске процесса приложения.

## Сборка и границы

Flutter3.47.7 / Dart3.13.5 / Go1.27.2, minSdk26. Go-модуль: `protocol/rivet`, gomobile AAR: `app/android/app/libs/rivet.aar`, сервер: `vendor-server/xio-rivet-linux-amd64`. Команды: `go test -race ./...`, `flutter analyze`, `flutter test`, `flutter build apk --release --split-per-abi`. Android-библиотеки выровнены на16КБ; сжатые native-библиотеки извлекаются ОС при установке. Подпись хранится вне исходников в `.signing`. SDK, ключи и тестовые реквизиты не входят в архив.

RIVET проверен в Android-эмуляторе и на VPS, но не на физическом Honor Magic V3. Windows не собран. Движок RIVET пока не подключён к desktop-интерфейсам; Linux-сборка проверяет интерфейс, а не desktop RIVET-туннель. SNI, TLS/QUIC-отпечаток, порт и форма потока остаются наблюдаемыми. Не заявляются полная неразличимость, устойчивость ко всем DPI/странам, отсутствие всех утечек, производственная готовность или независимый аудит. Подробные положительные и отрицательные результаты — в отчёте.
