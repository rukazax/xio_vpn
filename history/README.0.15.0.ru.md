# XIO 0.15 — автоматическое переключение и компактный интерфейс

[APK ARM64 для Honor Magic V3](releases/XIO-0.15.0-android-arm64-v8a.apk) · [исходники](releases/XIO-0.15.0-source.zip) · [отчёт о проверке](verification/VERIFICATION-0.15.ru.md) · [предыдущий выпуск](history/README.0.14.0.ru.md)

XIO означает **X in 1 out**. Рабочие Android-движки: WireGuard и AmneziaWG3.1. Полный ранее запрошенный набор AmneziaVPN, Android Tailscale/Headscale и экспериментальные RIVET пока не реализованы. Они не выдаются за работающие протоколы.

## Изменения 0.15

- «Настройки → Соединение»: время попытки 5–60 секунд, по умолчанию15. При неудаче HTTPS-проверки или отсутствии свежего handshake приложение отменяет запрос, отключает туннель и переходит к следующему протоколу **этого пользователя**. Ожидание разрешения Android на VPN не входит в тайм-аут; запуск/остановка службы ОС добавляет небольшое время. Настройка используется и плиткой без открытого Activity.
- Карточка пользователя: имя, цветной `admin` только для администратора, `online`/`offline`; месячный трафик в десятичных GB; «Поделиться»/«Отозвать». Недоступные действия отключены. Подробности протоколов, даты, on/off и ручное обновление убраны.
- Статистика запрашивается один раз при запуске процесса приложения. Открытие страницы, возврат из фона и смена вкладки не запускают новый SSH-запрос. При недоступном сервере сохраняется последний успешный снимок. Статус подключения относится к снимку, а не к непрерывному мониторингу. Создание/отзыв пользователя по-прежнему обновляет список доступа.
- В настройках пункт «Пользователи» показывает количество записей списка, включая отозванные. На главной удалён повторный IP:port, выбор сервера сохранён.
- Палитра перенесена из актуального CSS сайта-образца: фон Ink `#0c1118`, панели Slate `#151c26`, текст Mist `#e6ebf2`, акцент Lagoon `#35c2b5`. Светлая тема: `#eef1f5` / `#ffffff` / `#172030`. Текстовый акцент светлой темы затемнён до `#087f75` для контраста; кнопки остаются бирюзовыми. Сохранены автоматическая системная тема и локальные Noto Sans/fallback для13 языков; Noto Sans входит в системный стек сайта. Обновлены диалоги, карточки, ярлыки и фон запуска.
- Добавлено «Поддержать XIO» → https://x1o.org/pay, открывается в браузере. На18.10.2026 домен не разрешался DNS этой среды, поэтому доступность самой страницы не подтверждена.

## Сохранённые возможности

Импорт профиля XIO, WireGuard/AmneziaWG `.conf` и поддерживаемых экспортов Amnezia с автоматическим определением движка. Чужие подписки и конфигурации неинтегрированных движков не принимаются за рабочие. Профиль пользователя содержит отдельные ключи обоих рабочих протоколов. Выдача, отзыв, делегированные администраторы с лимитом одновременно действующих пользователей, перенос конфигурации сервера, переименование и флаги стран сохранены.

Root-пароль или SSH-ключ сохраняется отдельно в зашифрованном хранилище (Android Keystore; desktop — платформенное хранилище). Он автоматически подставляется для управления сервером. Экспорт сервера содержит SSH-доступ; обычный пользовательский экспорт его не содержит. SSH-ключ сервера запоминается автоматически, изменённый ключ не принимается молча.

«Настройки → Серверы → ⋮»: удалить только локальную запись или очистить управляемую установку XIO и после успеха удалить запись. Очистка удаляет собственные конфигурации, ключи, службы, правила и пакеты, добавленные установщиком и не используемые другими компонентами. Общие журналы ОС и следы у провайдера не стираются. Произвольные сторонние VPN-установки автоматически не удаляются.

Автоустановщик поддерживает Debian12/13, Ubuntu22.04/24.04/26.04 и CentOS Stream/Rocky/Alma/RHEL9/10, x86_64, systemd/TUN/IPv4. Испытания установки и обоих туннелей на Debian12, Ubuntu24.04 с UFW и CentOS Stream9 с firewalld/SELinux Enforcing относятся к [выпуску0.14](verification/VERIFICATION-0.14.ru.md); серверный код0.15 не менялся.

## Сборка и границы проверки

Flutter3.47.7 / Dart3.13.5; minSdk26; AmneziaWG Go `v3.1.20260814`. Команды в `app`: `flutter analyze`, `flutter test`, `flutter build apk --release --split-per-abi`. Подпись хранится вне исходников в `.signing`. Упаковка: `tools/package-source.py`; проверка архивов/известных тестовых секретов: `tools/audit-releases.py`.

Android проверяется на отдельном эмуляторе API35, 360×800 и увеличенном шрифте1.3; физический Honor Magic V3 не проверен. Ubuntu проверяет сборку и запуск интерфейса в Xvfb. Windows-бинарный выпуск не собран. HTTPS и handshake не доказывают отсутствие всех утечек, воспроизведение YouTube или устойчивость к DPI в разных странах. При раздельном туннелировании проверка сайта следует правилам приложения.
