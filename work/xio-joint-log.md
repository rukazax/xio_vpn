подхватить контекст, даже когда его сессия перегружена.

**Каскад (новое).** Прямого пути IPv4↔IPv6 между хостами нет: провайдер bridge не раздаёт IPv6
(проверено RA и `dhclient -6`), у exit нет IPv4. Транспорт — SSH L3 `ssh -w 0:0` через IPv4-прокси
провайдера exit (`vps-721137.ssh.vps1euro.fr:9046`):
- bridge: `/usr/local/sbin/xio-cascade-tunnel.sh` + `xio-cascade.service`, `tun0` `fd00:201::1/126`,
  IPv6 default → `tun0`;
- exit: `PermitTunnel yes`, IPv6 forwarding, `ip6tables` NAT66 в `eth0`;
- XIO сам строит `FORWARD -s fd78:1::/64 -i xioawg0 -o tun0`, поэтому каскад покрывает **все** протоколы.
- Замеры: `ping6` с bridge 68–77 мс; с AWG-клиента IPv4 3,5 МБ/с, IPv6 1,2 МБ/с; PMTU 1232 без фрагментации.
