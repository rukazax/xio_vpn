# XIO Client 0.22.3

Облегчённый клиент для подключения к существующим VPN-серверам. Версия 0.22.3+5012, пакет `app.x1o.client`. Устанавливается рядом с полным XIO. Главный экран использует ту же тему: большая кнопка подключения, состояние, сервер, протокол и счётчики трафика. Интерфейс и документация доступны на русском и английском.

## Подключение

1. [Скачайте APK](https://github.com/rukazax/xio_vpn/releases/tag/v0.22.3). Android 8.0/API 26 и новее; ARM32, ARM64, x86-64 или универсальная сборка. Физически проверен POCO X6 5G с Android 16/ARM64. Совместимость со всеми прошивками не заявляется.
2. Получите клиентский профиль у владельца сервера. Нажмите «Добавить профиль», вставьте ключ или выберите файл. Встроенных чужих серверов и учётных данных нет.
3. Выберите подключение и подтвердите системное разрешение VPN. Поддерживаются Xray/REALITY, RIVET/H3, RIVET/S1, AmneziaWG и OpenVPN/Cloak. Клиент подключает выбранный профиль и не заменяет его другим протоколом.
4. Для смены активного профиля подтвердите переключение. Старый туннель сначала останавливается. Между соединениями возможен выход без VPN; системная блокировка соединений без VPN настраивается в Android отдельно.

## Раздельное тунелирование

Отключите VPN, откройте правило на главном экране и сохраните режим: все приложения, только выбранные через VPN, выбранные в обход, только выбранные IP/CIDR через VPN или выбранные IP/CIDR в обход. Правила общие для профилей этого приложения. Режим по приложениям и режим по IP выбираются отдельно. Домены в список CIDR не добавляются.

Исключённый трафик идёт напрямую, если Android lockdown это разрешает. DNS берётся из профиля: при включении отдельных IP включите и нужный DNS-сервер либо используйте доступный в вашей сети вариант. Наличие статуса VPN само по себе не доказывает маршрут каждого приложения. Физические проверки выполнены отдельным тестовым приложением с наблюдением адреса выхода.

## Субклиенты по квоте

Обычный VPN-профиль права создавать других клиентов не даёт. Владелец обновляет сервер до ревизии 24 через полное XIO 0.22.3, создаёт аккаунт с положительным лимитом и выбирает «Поделиться». Подтверждение описывает включение HTTPS API на TCP 9444 и замену прежнего токена аккаунта. Внешний firewall провайдера также должен разрешать этот порт.

Клиент отдельно подтверждает импорт ограниченного аккаунта. Кнопка «Субклиенты» появляется только у такого профиля. Сервер проверяет остаток квоты, отзыв доступа и принадлежность субклиента при каждой операции. Созданный субклиент получает только свои VPN-профили; токен родителя и право дальнейшего делегирования ему не передаются. Отзыв освобождает место в квоте и блокирует дальнейшее подключение клиента.

Установка VPS, серверное SSH-администрирование, root/admin-ключи и серверные архивы в клиент не входят. Профили с административными полями отклоняются. В аккаунт передаются только HTTPS endpoint, публичный отпечаток сертификата, ограниченный токен и идентификаторы. Клиент закрепляет точный сертификат и срок действия, не следует перенаправлениям. Продление отдельного сертификата API требует действий владельца и новых профилей с новым отпечатком.

VPN-ключи и токен чувствительны: Android Keystore/AES-GCM защищает локальное хранилище, резервное копирование отключено. FLAG_SECURE сохранён. Удаление локального профиля не заменяет серверный отзыв доступа. Экспорт использует закрытый FileProvider и временное разрешение на конкретный файл.

При потере ответа операция сохраняет прежний ID и ключи. «Проверить незавершённое создание» не создаёт новый запрос с новым ID. Серверный незавершённый результат после аварии требует сверки владельцем; автоматического повторного исполнения нет.

## Проверка и ограничения

[Матрица физических и локальных проверок, изображения и схемы обоих приложений](../docs/dualstack/0.22.3.ru.md). Общий Flutter-набор: 113 прошли, 6 пропущены; клиентский режим: 13 прошли; сервер: 31 прошёл. Наборы частично пересекаются. Публичный IPv6 не проверен: разрешённый VPS не имеет IPv6-маршрута. IPv6-пакеты и серверные правила проверены в изолированной локальной сети. Полный аудит безопасности, нагрузка, автономность и устойчивость ко всем блокировкам не заявляются. API пока предварительный; перед массовым внедрением нужен отдельный production review транспортного слоя.

Сборка: `python3 client/build.py`. Проверка: `python3 client/verify.py`. Точный native runtime: `native-sources/android-runtime-0.22.3`; APK, подписи, зависимости и контрольные суммы приложены к релизу. Закрытые ключи подписи в исходники не входят.


Матрица пяти протоколов в обоих приложениях (20 HTTPS-проверок) выполнена на сборке 5011. В финальной 5012 нативное ядро/AAR не менялось: добавлены журналы жизненного цикла плитки без секретов. На 5012 отдельно проверены подключение/отключение основной кнопкой плитки, независимый HTTPS через VPN и контроль Xray в клиенте. Это не повтор всей матрицы на 5012.
