Политика конфиденциальности XIO Client
Редакция 23 октября 2026 года. Разработчик: Ерёмин Константин Александрович, er-ka@mail.ru.

Клиент подключается только к существующему серверу по импортированному клиентскому профилю. Профили и настройки хранятся на устройстве, секреты — в зашифрованном Android Keystore хранилище без резервного копирования. Защита не гарантирует безопасность скомпрометированного устройства. Запись ознакомления содержит редакцию, время UTC по часам устройства, язык и SHA-256 показанного текста; разработчику она не передаётся.

VpnService передаёт выбранный трафик с шифрованием до выбранного endpoint. Оператор сервера может видеть IP подключения, назначения и метаданные; HTTPS защищает содержимое отдельно. DNS использует настройки профиля. Проверка доступности обращается к выбранному HTTPS-сайту (по умолчанию youtube.com), который видит адрес выхода. При раздельном туннелировании проверка может идти напрямую; она не доказывает защиту остальных приложений. Исключённые приложения и IP идут напрямую, если это не запрещено системной блокировкой трафика без VPN.

Отдельно выданный API-токен аккаунта позволяет проверять квоту, создавать и отзывать только своих субклиентов через HTTPS API выбранного сервера с закреплённым сертификатом. Токен и незавершённая операция сохраняются в защищённом хранилище. В профиль субклиента входят только его VPN-ключи: токен родителя и SSH/root/admin-ключи не экспортируются. Данные субклиентов хранятся также на сервере.

Нет установки и администрирования VPS, SSH, раздачи VPN, геолокации endpoint, фоновой проверки релизов, аналитического или рекламного SDK и автоматической отправки crash-логов. Внешний файл выбирается через системный диалог; общего доступа к накопителю не требуется. Список запускаемых приложений читается локально для выбора правил VPN и не отправляется разработчику. Снимки экрана приложения запрещены через Android FLAG_SECURE.

Данные сохраняются до удаления профиля, очистки данных или удаления приложения. Удаление профиля с телефона не удаляет сервер и не отзывает доступ на нём. Выдачу доступа и обработку данных на сервере определяет его оператор. Связь с поддержкой добровольна; не передавайте пароли и закрытые ключи. Android отдельно запрашивает разрешение VPN; без согласия новое подключение не начинается.
