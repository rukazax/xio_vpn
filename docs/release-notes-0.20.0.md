# XIO 0.20.0

## Русский

Обновили настройки во всех клиентах. «Справка и FAQ» и «Лицензия и ответственность» находятся в «О XIO». Описания движков собраны в подразделе «Протоколы». Диагностика и журнал находятся в настройках соединения.

Добавили описание проекта, инструкции, FAQ, схемы и изображения на русском и английском.

Выберите файл в Assets:

- Android ARM64: `XIO-0.20.0-android-arm64-v8a.apk`.
- Android ARMv7: `XIO-0.20.0-android-armeabi-v7a.apk`.
- Android x86_64: `XIO-0.20.0-android-x86_64.apk`.
- Ubuntu x64: DEB или tar.gz.
- Windows x64: ZIP, распакуйте полностью.
- Все исходники, включая проект iOS и зависимости: `XIO-0.20.0-source.zip`.

Проверьте файл по `SHA256SUMS-0.20.0`. Android требует Android 8+. Windows остаётся сборкой для испытаний: интерфейс ранее проверен в Wine, нативная сеть требует проверки. Подписанного IPA нет. Протокольный код не менялся; новые гарантии безопасности не заявляются. 94 Flutter-теста прошли, 5 платформенных тестов пропущены. APK проверены по подписи, ярлыку и составу библиотек.

## English

Updated settings across clients. Help and FAQ, and Licence and responsibility are now under About XIO. Engine information is grouped under Protocols. Diagnostics and the session log are under Connection settings.

Added project descriptions, instructions, FAQ, diagrams and images in Russian and English.

Choose an asset:

- Android ARM64 devices: `XIO-0.20.0-android-arm64-v8a.apk`.
- Android ARMv7: `XIO-0.20.0-android-armeabi-v7a.apk`.
- Android x86_64: `XIO-0.20.0-android-x86_64.apk`.
- Ubuntu x64: DEB or tar.gz.
- Windows x64: ZIP; extract the entire archive.
- Full source, including the iOS project and dependencies: `XIO-0.20.0-source.zip`.

Verify downloads against `SHA256SUMS-0.20.0`. Android requires Android 8+. Windows remains a test build: the UI was previously checked in Wine, while native networking still needs testing. No signed IPA is available. Protocol code is unchanged; no additional security guarantees are claimed. 94 Flutter tests passed and 5 platform-specific tests were skipped. APK signatures, launchers and native payloads were checked.
