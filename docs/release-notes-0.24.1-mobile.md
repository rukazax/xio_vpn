# XIO 0.24.1 — мобильный выпуск: каскад двух серверов

> Сборка Android: `0.24.1+5018`. Пакеты: `app.xio.xio` (Full) и `app.xio.client` (Client).
> Подпись прежняя: `CN=x1o Development`, SHA-256 `e4e81b12…c9671` — обновление поверх 0.23.x/0.24.x без удаления.

## Что нового

### Каскад: IPv4 → bridge → IPv6 exit

Платная функция (подписка — заглушка). Устройство приходит по IPv4 на промежуточный
сервер **bridge**, тот держит защищённый туннель **только по IPv6** до второго сервера
**exit**, и трафик выходит из сети, где работает один IPv6.

* отдельный экран **«Каскад»** — один, без прокрутки, целиком в экран телефона:
  три станции с флагами стран, линии состояния, пинг, «Переподключить»;
* плашка «Платная функция. Требуется подписка» и кнопка «Активировать» (заглушка);
* вход: Full — вкладка «Соединение» → «Каскад: два сервера»; Client — кнопка рядом
  с «Субклиенты»/«Проверка соединения»;
* в форме установки сервера (Full) — галочка **«Включить каскад (по подписке)»**:
  после установки приложение показывает точную команду для bridge и открывает схему.

### Серверная часть

Установка каскада — из репозитория (`deploy/cascade`), в отдельном контейнере:

```bash
curl -fsSL https://raw.githubusercontent.com/rukazax/xio_vpn/main/deploy/cascade/terminal-install.sh \
  | bash -s -- --role bridge --exit-host <ipv6-exit>
```

Требуется container runtime (docker/podman); для роли bridge — глобальный IPv6.
Белые списки раздельного туннелирования живут на bridge и обновляются еженедельно.
Управление сервисами и пользователями — через защищённую веб-панель (`server/webui`,
TLS + Bearer-токен, порт 10443).

## Проверено на устройстве

POCO X6 5G (Android 16, arm64, `909f194a`):

* Full 0.24.1 ставится и запускается; вкладка «Соединение» → «Каскад: два сервера»;
* экран каскада открывается: «Платная функция. Требуется подписка», пинг, «Переподключить»,
  «Активировать»; все элементы в границах 134…2676 при экране 1220×2712 — **без прокрутки**;
* `logcat` без `RenderFlex overflowed`;
* Client 0.24.1: кнопка «Каскад: два сервера» на экране подключения, экран открывается.

Установка на MIUI/HyperOS: системный `adb install` может вернуть
`INSTALL_FAILED_USER_RESTRICTED`. Рабочий путь:

```bash
adb push XIO-Full-0.24.1-android-arm64-v8a.apk /data/local/tmp/xio.apk
adb shell pm install -r -g /data/local/tmp/xio.apk
```

## Что не проверено

* реальный трафик через два сервера: у тестового bridge (81.177.142.37) нет глобального
  IPv6, поэтому туннель bridge → exit (2a0c:b641:1a0:800::2a2) физически не поднять;
* подписка и оплата — заглушка (`CascadeFeatureGate.enabled == false`);
* перебор нескольких bridge/exit — заглушка (`CascadeServerPool`);
* Windows/Ubuntu сборки в этот выпуск не входят — они выходят отдельными предрелизами.
