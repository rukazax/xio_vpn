## Limitations

- only RIVET/S1 was exercised; H3, AWG, Xray and Cloak were not re-run for 0.24.0;
- public IPv6 from the client to the server was not re-tested for 0.24.0;
- Linux packages were built on Debian 13; the GUI launch was not tested in 0.24.0. The Windows Client is not part of this release;
- iOS was not built;
- the server archive was packaged with the pinned native binaries; the source-fingerprint guard was overridden for this build only (the pin predates later commits) and the committed metadata was left unchanged.
