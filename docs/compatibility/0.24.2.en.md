# Compatibility 0.24.2

Date: 2026-11-04. Version: **0.24.2**.

## What changed in 0.24.2

- `release-0.24.0` (what used to ship as rc13) merged with the main-side work: cascade, APK size,
  battery;
- the AWG descriptor is fixed (`F_DUPFD_CLOEXEC`): the mobile package no longer fails at random;
- the Xray config is built directly in protobuf, `xio-tunnel.exe` is 31 450 112 B (−11.58 %);
- the server package ships `readiness.py` and `xio-ready.service`, `RECIPE` is 26, text members are LF;
- the two-server cascade: app screen, install checkbox, `deploy/cascade/*`, web panel `server/webui`
  (TLS + token, port 10443), terminal install;
- CJK subset and an honest client pipeline: Full APK ≈ −7.1 MiB, Client without the server archive;
- the watchdog and the status poll no longer spend radio time, prefs writes or repaints on a healthy
  tunnel.

## Not verified

- a live connection on the 0.24.2 build: the last live RIVET/S1 run was 0.24.0 (2026-10-31);
- live traffic through the cascade: the bridge `81.177.142.37` has no global IPv6, so the tunnel to the
  exit (`2a0c:b641:1a0:800::2a2`) cannot come up;
- local Windows builds and tests: WDAC/Smart App Control blocks `dartaotruntime.exe`, `gen_snapshot.exe`,
  `impellerc.exe` and `flutter_tester.exe` (`WinError 4551`);
- the Windows ZIP 0.24.2: if the rebuild does not land in time, the rc13 artifact ships;
- the x86_64 ABI on a device; iOS was not built;
- public IPv6 from the client to the server was not re-tested for 0.24.2.

## Limitations

- the cascade subscription is a stub (`CascadeFeatureGate.enabled == false`) and server rotation is a
  stub (`CascadeServerPool` holds one bridge/exit);
- split tunnelling is driven by whitelists on the bridge and refreshed weekly, not in real time;
- Linux packages are built on Debian 13; the GUI launch on a clean Ubuntu was not tested;
- the server needs an external TUN and delegated `CAP_NET_ADMIN`/`CAP_NET_RAW`: without them the install
  stops at preflight instead of trying to bypass host restrictions;
- the cascade needs a container runtime (docker/podman); the bridge role needs global IPv6.
