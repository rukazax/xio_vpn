# Совместимость 0.23.1

Дата: 31.10.2026. Сборка: **0.23.1+5016**. Ниже — что именно проверено, когда и чем, без «✅ по декларации».

## Что изменилось в 0.23.1

- проверка соединения больше не требует внешнего сайта: туннель подтверждается свежим обменом, счётчиками и DNS через туннель; опрос сайта — необязателен и по умолчанию выключен;
- порядок маршрутов: выбранный профиль → варианты того же endpoint с другим протоколом → остальные профили;
- живой контроль связи (сторож раз в 15 с), автопереподключение с паузами 5/15 с до возвращения сервера;
- версия 0.23.1+5016.

## Ограничения этой проверки

- один физический Android (POCO X6 5G, Android 16, ARM64); ARM32 и x86-64 — только подписанные сборки;
- у клиента в локальной сети нет глобального IPv6, поэтому сквозной IPv6-payload проверялся из network namespace на самом VPS;
- полная матрица «5 транспортов × 3 платформы» на 0.23.1 не прогонялась: проверены RIVET-S1 (Android, Linux, внешний IPv6) и серверная часть;
- Windows x64: сборка и тесты; живое подключение через GUI в 0.23.1 не перепроверялось;
- Xray/REALITY по-прежнему не подключается на паре «клиент 0.23.x + шлюз Xray 26.7.28»;
- iOS не собирался (вне объёма).
