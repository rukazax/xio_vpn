# Compatibility 0.23.1

Date: 2026-10-31. Build: **0.23.1+5016**. What was verified, when and how — not "✅ by declaration".

## What changed in 0.23.1

- the connection check no longer requires an external site: the tunnel is confirmed by a fresh exchange, counters and DNS through the tunnel; the site probe is optional and off by default;
- route order: selected profile → same-endpoint variants with another protocol → other profiles;
- live link watchdog (every 15 s) with auto-reconnect and 5/15 s backoff until the server returns;
- version 0.23.1+5016.

## Limits of this verification

- one physical Android (POCO X6 5G, Android 16, ARM64); ARM32 and x86-64 are build-verified only;
- the client's LAN has no global IPv6, so the end-to-end IPv6 payload was executed from a network namespace on the VPS itself;
- the full "5 transports × 3 platforms" matrix was not re-run on 0.23.1: RIVET-S1 (Android, Linux, outer IPv6) and the server side were exercised;
- Windows x64: build and tests; a live GUI connection was not re-checked on 0.23.1;
- Xray/REALITY still does not connect on the "0.23.x client + Xray 26.7.28 gateway" pair;
- iOS was not built (out of scope).
