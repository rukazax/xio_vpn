# XIO стал общедоступным / XIO is now public

18 октября / October 2026 · Публикация проекта / Public launch

## Русский

Открыли репозиторий XIO. Исходники, документация и релизы доступны без приглашения. Добавили тематические метки для поиска и открыли Discussions для вопросов и обратной связи.

Опубликовали представление проекта на внешней площадке Telegraph:

- [На русском](https://telegra.ph/XIO-otkrytyj-klient-dlya-svoego-VPN-servera-i-ehksperimentalnye-transporty-RIVET-10-18).
- [На английском](https://telegra.ph/XIO-an-open-client-for-your-own-VPN-server-and-experimental-RIVET-transports-10-18).
- [Анонс и обсуждение](https://github.com/rukazax/xio_vpn/discussions/1).

В статьях есть схемы, данные измерений и ограничения. Это материалы самого проекта с раскрытием помощи ИИ, а не независимые отзывы. Охват и привлечение пользователей пока не измерены. Платная реклама не покупалась.

Приложение остаётся версии 0.20.0. Android и Ubuntu доступны в [релизе](https://github.com/rukazax/xio_vpn/releases/tag/v0.20.0), Windows — предварительная сборка, iOS — исходники без подписанного IPA. Этот этап меняет доступность и материалы проекта, не протокольный код.

## English

The XIO repository is public. Source, documentation and releases are available without an invitation. Added discovery topics and enabled Discussions for questions and feedback.

Published project introductions on Telegraph:

- [Russian](https://telegra.ph/XIO-otkrytyj-klient-dlya-svoego-VPN-servera-i-ehksperimentalnye-transporty-RIVET-10-18).
- [English](https://telegra.ph/XIO-an-open-client-for-your-own-VPN-server-and-experimental-RIVET-transports-10-18).
- [Announcement and discussion](https://github.com/rukazax/xio_vpn/discussions/1).

The articles include diagrams, measurement evidence and limitations. They are project-authored with AI assistance disclosed, not independent reviews. Reach and user acquisition have not been measured. No paid advertising was purchased.

Application version remains 0.20.0. Android and Ubuntu are in the [release](https://github.com/rukazax/xio_vpn/releases/tag/v0.20.0); Windows is a preview, and iOS provides source without a signed IPA. This stage changes project availability and publication material, not protocol code.
