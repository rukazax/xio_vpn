# XIO Client: готовое подключение и ограниченные субклиенты

## XIO Client 0.22.2 — подключение без управления сервером

XIO Client — отдельное облегчённое приложение Android для подключения к уже настроенным VPN-серверам. Получите профиль у владельца, импортируйте его, выберите сервер и подключитесь. Создавать VPS и вводить серверный SSH-ключ в клиенте не требуется. Клиент устанавливается рядом с полным XIO.

Главный экран использует тему основного приложения: большая кнопка подключения, состояние соединения, выбор сервера, протокол и счётчики трафика. Есть переключение серверов и раздельное туннелирование по приложениям либо IP-сетям. Доступные транспорты: Xray, RIVET/S1, RIVET/H3, AmneziaWG и Cloak.

| Приложение | Для чего нужно |
|---|---|
| Полный XIO | Владелец устанавливает и обслуживает сервер, создаёт аккаунты, задаёт квоты и выдаёт доступ. |
| XIO Client | Пользователь подключается к готовым серверам; аккаунт с выданным правом может создавать и отзывать своих субклиентов в пределах квоты. |

**Субклиенты.** Кнопка появляется только после импорта профиля аккаунта с ограниченным API-доступом. Сервер проверяет права, отзыв доступа, принадлежность субклиента и остаток квоты при каждой операции. Обычный VPN-профиль такого права не даёт. Созданный субклиент получает только собственные VPN-данные и не наследует право создавать следующих клиентов.

**Серверные ключи остаются у владельца.** Экспорт root/admin SSH-ключей в клиентский профиль заблокирован. Вместо них выдаётся случайный токен с ограниченными действиями: статус аккаунта, создание и отзыв своих субклиентов. Он хранится зашифрованным на Android; на сервере хранится его хеш. HTTPS проверяет закреплённый сертификат. При потере ответа создание не повторяется автоматически с новым ID.

Требуется **Android 8.0+**; доступны ARM32, ARM64, x86-64 и универсальный APK. Для субклиентов владельцу нужно обновить сервер до ревизии 21 через полное приложение 0.22.2 и заново выдать профиль аккаунта с положительной квотой. Включение отдельного HTTPS API на TCP 9444 подтверждается владельцем в приложении. Для обычного подключения к готовому профилю этот API не нужен.

Это **тестовый релиз**. Локально прошли анализ, 110 общих Flutter-тестов (5 пропущены), отдельно 10 тестов клиентского режима и 26 серверных тестов. Проверены подписи APK, состав и выравнивание библиотек. Новый клиент и API субклиентов пока не проверены на физическом Android и действующем VPS; прежние испытания полной версии 0.22.1 этого не доказывают. Серверный API предварительный: до массового развёртывания нужны отдельная проверка установки, нагрузки и транспортного слоя. Сборки для ПК остаются 0.22.0.

## Как выдать доступ

1. В полном приложении владельца отключите VPN и откройте пользователя с правом создавать клиентов и положительной квотой.
2. Выберите «Поделиться». Подтвердите установку API на TCP 9444 и перевыпуск токена. При необходимости разрешите порт в панели провайдера.
3. Передайте новый профиль аккаунта в XIO Client. Проверьте адрес API в запросе импорта.
4. Откройте «Субклиенты»: сервер покажет использованную квоту и доступный остаток. Создайте клиента и передайте только его профиль.
5. При потере ответа используйте проверку незавершённой операции. Если сервер сохранил лишь намерение, нужна сверка владельцем; новая операция автоматически не выполняется.

Обновление токена аккаунта не передаёт серверный ключ. Ранее выданные SSH-пакеты администрирования клиент не принимает. Сертификат API действует 365 дней; после его замены потребуются новые профили с новым отпечатком.
