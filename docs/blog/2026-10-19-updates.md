# XIO 0.21: обновления из приложения / Updates inside the app

## Русский

Добавили в «О XIO» GitHub и кнопку «Поделиться приложением». Ссылка ведёт на релиз с файлами для установки. На телефоне открывается обычное меню отправки, на компьютере ссылка копируется в буфер обмена.

В настройках приложения появилась проверка обновлений. Новую версию можно установить, отложить или пропустить. Пропуск относится к одному релизу, следующий появится снова. Для каждой установки выбирается пакет своей системы и архитектуры.

Автоматическая проверка назначается через семь суток со случайной задержкой до 24 часов. Срок сохраняется после перезапуска. Так устройства проверяют GitHub в разное время. Пакет скачивается после согласия пользователя. Описание релиза подписано Ed25519, размер и SHA-256 проверяются до установки.

Android использует системный установщик и запрашивает его подтверждение. На Ubuntu установка DEB проходит через разрешение ОС. В Windows отдельный процесс заменяет файлы после закрытия XIO и сохраняет предыдущую папку до подтверждения запуска новой версии. После успешной установки загруженный пакет удаляется. В iOS открывается страница релиза; устанавливаемой подписанной сборки для iPhone пока нет.

Android умеет проверять метаданные в фоне и показывать уведомление. На компьютере приложение проверяет обновления во время работы или после запуска, если срок уже прошёл. Ограничения батареи и сети могут задержать проверку на телефоне.

Версия 0.21 впервые включает этот механизм. Для перехода с 0.20 установите новый пакет обычным способом. Дальнейшие подписанные релизы уже сможет находить приложение.

## English

About XIO now includes GitHub and Share app. The link opens the release with installation files. Phones use the system share sheet; desktop clients copy the link to the clipboard.

Application settings now offer update checks. Install a new version, postpone it or skip that release. Skipping one release does not hide the next. XIO selects a package for the device's OS and architecture.

Automatic checks run after seven days plus a random offset of up to 24 hours. The due time survives restarts, spreading requests across devices. Package downloads require user approval. An Ed25519 signature protects the release manifest; package size and SHA-256 are checked before installation.

Android uses its system installer and requires confirmation. Ubuntu requests OS authorization to install the DEB. Windows replaces files after XIO exits and keeps a backup until the new version confirms startup. A successful installation removes the downloaded package. iOS opens the release page; a signed installable iPhone build is not yet available.

Android can check metadata in the background and show a notification. Desktop checks run while the app is open, or after launch when overdue. Battery and connectivity restrictions may defer phone checks.

0.21 introduces this mechanism. Install it normally over 0.20; the app can discover subsequent signed releases.
