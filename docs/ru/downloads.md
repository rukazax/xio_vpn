## Windows x64, 0.22.5

- [XIO Client · Windows x64 ZIP](https://github.com/rukazax/xio_vpn/releases/download/v0.22.5/XIO-Client-0.22.5-windows-x64.zip)

В архиве `XIOClient.exe`, `data/`, помощник `libexec/xio-tunnel.exe`, официальный `wintun.dll` и
лицензии. Приложение не подписано сертификатом издателя, поэтому Windows покажет предупреждение
SmartScreen. Подключение требует прав администратора: помощник меняет маршруты и DNS.
