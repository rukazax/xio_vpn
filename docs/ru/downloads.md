Android требует Android 8+. Ubuntu: 22.04+ x64. Windows ZIP — для испытаний; приложение не подписано сертификатом издателя, нативная работа Wintun/UAC ещё требует проверки. Для iOS нет IPA: нужны Mac/Xcode и подпись Apple.

После загрузки проверьте сумму файла: `sha256sum ИМЯ_ФАЙЛА` на Linux или `Get-FileHash ИМЯ_ФАЙЛА -Algorithm SHA256` в PowerShell. Сравните результат с SHA256SUMS. Хеш проверяет целостность, но сам по себе не является подписью издателя.
