# Протоколы XIO 0.22

[English](../en/protocols.md) · [Инструкция](guide.md)

| Подключение | Android | Ubuntu / Windows | Назначение и ограничения |
|---|---|---|---|
| Xray: VLESS, VMess, Trojan | Да | Да | TLS/REALITY и поддерживаемые XHTTP, TCP, WebSocket, gRPC, HTTP Upgrade. Параметры должны соответствовать серверу |
| RIVET/S1 | Да | Да | Экспериментальный транспорт XIO через TLS/WebSocket; серверный сертификат закреплён в профиле |
| RIVET/H3 | Да | Да | Экспериментальный транспорт XIO через HTTP/3/QUIC; необходим доступный UDP |
| AmneziaWG | Да | Да | Обфускация транспорта AWG, включая проверяемые поля 3.1. Блокировку всего UDP или IP не устраняет |
| Cloak | Да | Нет | Cloak с внутренним OpenVPN. Отдельный OpenVPN не предлагается |
| RIVET для iOS | Исходный проект | — | S1/H3 реализованы в исходниках; подписанной IPA и проверки на Apple-устройстве нет |

Обычные WireGuard, OpenVPN, IKEv2, Shadowsocks и Tailscale удалены из поддерживаемых клиентских подключений. Их старые отдельные профили не подключаются; смешанные пользовательские пакеты сохраняют поддерживаемые конфигурации. Нужные Cloak библиотеки OpenVPN и общая инфраструктура AWG остаются. Это выбор состава продукта, а не доказательство, что удалённые протоколы нигде не работают.

Автоматика перебирает только доступные конфигурации одного пользователя. По умолчанию порядок: Xray → RIVET/S1 → Cloak → AWG → RIVET/H3; платформа пропускает отсутствующие движки. Приоритет можно изменить. После тайм-аута приложение отключает неудачную попытку и пробует следующий вариант. Одиночный сторонний профиль не получает выдуманных резервных протоколов.

RIVET использует существующие криптографические библиотеки. В 0.22 его сетевой формат не менялся. Проверенный импорт VLESS Encryption выполняет криптографию средствами Xray и не является новым шифром XIO. Независимого аудита RIVET и доказательства неотличимости от обычного браузера нет. Подробнее: [статья с моделью ограничений](../blog/2026-10-19-restricted-networks.md), [проверка идей из видео](../research/2026-10-19-video-protocols.ru.md).

![Сеть и точка входа](../images/allowlist-entry-ru.svg)

Даже TLS-туннель оставляет видимым IP точки входа. Для строгого белого списка нужна доступная точка входа и рабочий маршрут от неё к выходу. XIO не предоставляет автоматически доступный CDN или чужой сайт в качестве посредника.
