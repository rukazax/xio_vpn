# Справка и FAQ

[English](../en/faq.md) · [Главная](../../README.ru.md)

**Не подключается.** Проверьте доступность VPS, активность профиля, порты, дату устройства и сайт проверки. Откройте «Настройки → Соединение → Диагностика». Не публикуйте полный профиль и SSH-пароль вместе с журналом.

**Туннель работает, но приложение переключает протокол.** Проверочный сайт может быть недоступен с VPS. Для проверки задайте https://example.com. Верните удобный сайт после выяснения причины.

**Где протоколы, справка и лицензия?** «Настройки → О XIO». Все протоколы собраны в подразделе «Протоколы».

**Где диагностика?** «Настройки → Соединение → Диагностика».

**Почему нет IPA?** Для iPhone нужны Mac, Xcode, команда Apple Developer и подпись NetworkExtension. Сейчас публикуются исходники, не готовый IPA.

**Можно ли импортировать любой VPN?** Только поддерживаемые форматы и движки. Набор отличается по платформам.

**Можно ли передать административный экспорт?** Да, но он передаёт секреты и права управления сервером. Для обычного доступа делитесь пользовательским профилем.

**Почему статус пользователя не обновляется постоянно?** Статистика загружается один раз при запуске приложения. Это снимок состояния, а не постоянный мониторинг.

**Что удаляет очистка?** Принадлежащие XIO VPN-компоненты и их конфигурации в пределах реализованного установщика. Полное стирание резервных копий провайдера и системных журналов не гарантируется.

**Подходит ли VPN для полной анонимности?** Такой гарантии нет. Провайдер, владелец VPS и посещаемые сервисы видят разные сетевые метаданные. HTTPS защищает содержимое отдельно от VPN.
