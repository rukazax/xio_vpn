# Вопросы и ответы

[English](../en/faq.md) · [Инструкция](guide.md)

**Почему не подключается ни один протокол?** Проверьте доступность IP сервера, SSH, DNS, время устройства и журнал в настройках соединения. Смена протокола не устраняет запрет самого IP. Один тайм-аут не устанавливает причину фильтрации.

**Где список протоколов?** Настройки → Соединение → Протоколы. Автоматика использует только профили выбранного пользователя и доступные движки платформы.

**Почему старый профиль исчез?** В 0.22 удалены отдельные WireGuard, OpenVPN, IKEv2, Shadowsocks и Tailscale. Импортируйте поддерживаемый профиль. Внутренний OpenVPN для Cloak сохранён.

**Нужен ли root для обычного VPN?** Нет. Root нужен для VPN при раздаче на Android. Без root будет сообщение «Необходим root». Honor без root не получает эту возможность от одного переключателя.

**Как проверить раздачу?** С подключённого устройства проверьте внешний IP при VPN и отсутствие доступа после его отключения. Перезапустите точку доступа после настройки offload. На прошивках с обходом netfilter требуется отдельная проверка. Windows ICS экспериментален, нужен администратор и включённый хот-спот.

**Обновится ли сервер вместе с клиентом?** Управляемый сервер обслуживается при запуске/открытии управления, если VPN выключен, сохранённый SSH-доступ работает и ключ совпадает. При активном VPN обновление откладывается. Рецепт 19 отключает старые службы XIO; ошибка запуска вызывает откат.

**Где iOS-приложение?** В репозитории есть исходный проект, готовой подписанной IPA пока нет.

**Гарантирован ли обход блокировок?** Нет. Нет полевых измерений этой сборки у операторов РФ и независимого аудита RIVET. Доступность входа и маскировка транспорта — разные задачи.
