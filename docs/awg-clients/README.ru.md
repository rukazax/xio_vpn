# Статичный AmneziaWG для роутеров и iPhone

XIO-клиент умеет перебирать транспорты и следить за связью, но на роутере (Jeton AX3000 Pro BK)
и на iPhone с приложением AmneziaVPN его нет. Для таких устройств выдаётся **один статичный
AWG-профиль**: подключение есть, перебора протоколов и сторожа связи на устройстве нет —
это осознанное упрощение.

## Выдача профиля

На сервере, который терминирует AmneziaWG (bridge), после установки серверного пакета 0.24.1
(скрипт ставится в `/usr/local/sbin/xio-peer.py`):

```sh
python3 /usr/local/sbin/xio-peer.py router-jeton --qr
```

Скрипт (`tools/xio-peer.py` в репозитории) делает всё сам:

1. генерирует пару ключей через `wg genkey` / `wg pubkey` — на сервер (`admin.py`) уходит только
   публичный ключ, а приватный попадает в файл профиля и передаётся устройству один раз; после
   импорта файл на сервере лучше удалить (`rm /root/<имя>.conf`);
2. вызывает `admin.py` с действием `add-awg` (передаётся только публичный ключ);
3. подставляет приватный ключ в шаблон и пишет `/root/<имя>.conf` с правами 600;
4. печатает JSON с `slot`, `endpoint` и путём к файлу, а с `--qr` — ещё и QR-код в терминал
   (для QR нужен `qrencode`: `apt-get install -y qrencode`; без него QR молча не печатается).

В профиле: адрес `10.78.0.<slot>/24` и `fd78:1::<slot в hex>/64`, параметры обфускации
`Jc/Jmin/Jmax/S1/S2/H1..H4` из развёртывания, `Endpoint <host>:51821`, `AllowedIPs 0.0.0.0/0, ::/0`,
`MTU 1232`, DNS `9.9.9.9, 2620:fe::fe`, `PersistentKeepalive 25`.

Отозвать доступ: `admin.py` действие `revoke` с `id` пользователя (как для обычного пользователя).

## Импорт

### iPhone / AmneziaVPN (и Android)

1. Передать файл на телефон (AirDrop, iCloud Drive, Telegram «в файлы»).
2. Открыть AmneziaVPN → «+» → **«Файл с настройками подключения»** → выбрать файл.
3. На экране «Новое соединение» нажать **«Подключиться»** и разрешить VPN.

Проверено на POCO X6 5G (Android 16), AmneziaVPN: профиль импортируется, подключение
устанавливается, `tun0` получает `10.78.0.2/24` и `fd78:1::2/64`. На iPhone шаги те же; сам
тест на iOS не проводился — приложение AmneziaVPN использует тот же формат `.conf`.

### Роутер Jeton AX3000 Pro BK

В веб-интерфейсе роутера: VPN → AmneziaWG → «Импорт конфигурации» → загрузить `.conf`.
Если импорт файла недоступен, параметры вводятся вручную с того же экрана: приватный ключ,
адрес, ключ сервера, endpoint, `Jc/Jmin/Jmax/S1/S2/H1..H4`.

## Что работает и чего нет

| Возможность | XIO-клиент | Статичный AWG |
|---|---|---|
| Перебор транспортов при блокировке | да | нет |
| Живой сторож и переподключение XIO | да | нет (только `PersistentKeepalive`) |
| Проверка связи XIO (readiness) | да | нет |
| Учёт трафика на сервере | да | да (счётчики AWG) |
| IPv4-интернет | через сервер входа | через bridge (его NAT) |
| IPv6-интернет | через exit (каскад) | через exit (каскад) |
| MTU профиля | 1280 (клиент XIO) | 1232 (замер PMTU каскада) |

## Ограничения

- У exit нет IPv4-адреса, поэтому IPv4-трафик выходит через bridge, а IPv6 — через exit.
- Пропускная способность каскада ограничена SSH-транспортом: замер 03.11.2026 — 3,5 МБ/с IPv4,
  1,2 МБ/с IPv6.
- Профиль статичный: смена точки входа или ключа — новой выдачей профиля.
